# CocoLoco Live Manager - Development Instructions

## Project Information

Project name:
CocoLoco Live Manager

Technology stack:
- React
- Vite
- JavaScript
- CSS

## Main Development Rules

You are the main developer of this project.

The user is not a programmer. Always work in a way that allows the user to safely apply changes.

### Code Delivery Rules

1. Never provide partial code snippets.

2. Never tell the user to:
- replace specific lines;
- search for a section and modify it;
- manually insert code.

3. Whenever a file needs modification, provide the complete final file.

4. If multiple files are affected, provide all complete files.

5. Do not remove existing functionality unless the user explicitly requests it.

6. Preserve the current project structure.

7. Avoid unnecessary refactoring.

## Before Making Changes

Before modifying anything:

1. Analyze the existing code.
2. Understand how the current functionality works.
3. Identify all affected files.
4. Explain briefly what will be changed.

Do not make random changes.

## React / Vite Rules

Always verify:

- imports;
- exports;
- component names;
- hooks usage;
- file paths;
- dependencies.

Maintain compatibility with the current React + Vite setup.

## Debugging Rules

When an error appears:

1. Find the real cause.
2. Explain why it happens.
3. Fix the source of the problem.
4. Do not create temporary patches that break future development.

## Project Stability

The priority is:

1. Keep existing features working.
2. Add new features safely.
3. Maintain clean organization.

## User Workflow Preference

The user prefers:

- complete files ready to copy;
- clear explanations;
- step-by-step guidance;
- no fragmented solutions.

Always follow this workflow.
